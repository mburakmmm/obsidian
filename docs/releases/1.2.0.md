# Obsidian 1.2.0

Obsidian 1.2.0 adds an opt-in NOX 2.2.70 terminal sink and uses a circular buffer for bounded memory logging. The existing core remains compatible with NOX 2.1.0.

- `TerminalSink` writes to stdout, preserves NOX print ordering and reports sanitized write failures. It can be registered directly on a logger with the text or JSONL format.
- `MemorySink` replaces its oldest slot after filling. Public FIFO reads, snapshots, drop counts and close behavior are preserved.
- File sink verification covers an operating-system write rejection after opening the file. Other sinks still receive masked records.
- The synchronous API and `obsidian.log.v1` schema remain in use. Async dispatch requires the upstream lifecycle capabilities listed in ADR-0011.
- The release attaches a CycloneDX 1.5 SBOM. Codex users can enable repository-local RTK and Graphify hooks through hook review.

Install the tagged version with `noxc add obsidian --ref v1.2.0`.
