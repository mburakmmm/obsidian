# Obsidian 1.1.0

Obsidian uses NOX 2.2.38 for development and releases. Consumer compatibility with NOX 2.1.0 is checked on macOS ARM64, Linux ARM64 and Linux x64 with LLVM and QBE.

- The synchronous API and `obsidian.log.v1` JSONL schema carry forward from 1.0.0.
- The GitHub release includes `obsidian-v1.1.0.cdx.json`, a CycloneDX 1.5 SBOM for the tagged package.
- The public registry submission uses the immutable `v1.1.0` ref, along with the package description, search tags and `source: nox`.
- Async dispatch remains unsupported under the worker lifecycle findings in ADR-0011.

Install the tagged version with `noxc add obsidian --ref v1.1.0`.
